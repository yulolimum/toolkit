# Scripts

Standalone command-line automation for development, mobile delivery, time tracking, media, and 3D printing tasks. Scripts are self-contained task files rather than reusable application modules or a shared script library.

HueForge swatch generation uses the artwork’s actual thickness and layer heights to create one square step per printed layer. The card uses a near-square grid. Unused cells contain no geometry and precede the ascending steps. The slicer controls filament changes.
