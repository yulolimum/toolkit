# toolkit-graph-dev-v1

Research a feature into a plan bundle. Implement an existing bundle in dependency order.

## What it does

- Maps a feature surface and writes a bundle.
- Defines work units and their dependencies.
- Implements incomplete units from a bundle.

## What to expect

Research has scope and decision gates. Implementation waits for a scope decision, runs unit checks, and reports risks.

## How to use

Give an agent a feature objective to research. Give it a bundle path, ticket, or unit ID to implement.

## Project references

Store project-specific references in `references/`. This repository ignores them. Do not commit NDA material.
