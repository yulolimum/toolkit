# toolkit-react-provider-pattern

Create or refactor React context providers with one consistent pattern.

## What it does

- Creates a private data hook.
- Infers the context type from that hook.
- Adds a thin provider and a guarded consumer hook.

## What to expect

The consumer hook either throws outside its provider or runs the data hook as a fallback.

## How to use

Ask an agent to create or refactor a React context provider or consumer hook.
