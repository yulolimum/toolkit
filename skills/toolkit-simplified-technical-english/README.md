# toolkit-simplified-technical-english

Rewrite selected prose with the upstream ASD-STE100 skill.

## What it does

- Reads the pinned upstream instruction set.
- Applies its ASD-STE100 writing workflow.
- Reports when it cannot read the upstream source.

## What to expect

The skill uses the upstream instructions as its source of truth.

## How to use

Ask an agent for an STE or ASD-STE100 rewrite of identified prose.
