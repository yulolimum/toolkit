# toolkit-living-docs

Maintain agent-facing living documentation in `.agents/docs`.

## What it does

- Creates and updates the documentation registry.
- Writes focused project, technical, and domain briefs.
- Audits documentation for current and useful context.

## What to expect

The skill starts from the registry. It reads only the briefs that apply to the task.

## How to use

Ask an agent to create, refresh, audit, or scaffold living documentation. Do not use it for ordinary README edits.
