# toolkit-humanizer

Edit prose to remove AI-style writing while keeping its facts and intent.

## What it does

- Preserves facts, voice, structure, and formatting.
- Removes repetitive or artificial wording.
- Improves prose for people who read it.

## What to expect

The skill changes prose only. It does not change code, data, or the intended message.

## How to use

Ask an agent to humanize a document, ticket, pull request description, or message.
