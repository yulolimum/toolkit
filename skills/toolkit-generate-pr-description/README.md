# toolkit-generate-pr-description

Generate a concise pull request description from the current branch diff.

## What it does

- Finds the relevant base branch and diff.
- Summarizes the user-visible and technical changes.
- Applies an editorial pass when you select one.

## What to expect

The skill reads the diff before it writes the description. It asks for missing review context when needed.

## How to use

Ask an agent to prepare a pull request description or release-note summary.
