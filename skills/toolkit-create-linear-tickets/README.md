# toolkit-create-linear-tickets

Create and update Linear tickets with a consistent draft and approval process.

## What it does

- Checks the workspace and team context.
- Proposes labels, projects, and estimates.
- Uses a structured ticket description.

## What to expect

The skill prepares a draft first. It does not create a ticket until you give explicit approval.

## How to use

Ask an agent to create, update, or comment on a Linear ticket.
