# toolkit-typescript-script-pattern

Write TypeScript command-line automation with a consistent structure.

## What it does

- Defines prompts and command-line arguments.
- Adds caching and clear logging.
- Uses a predictable `tsx` execution pattern.

## What to expect

The skill keeps automation scripts easy to run, inspect, and maintain.

## How to use

Ask an agent to create or update a TypeScript command-line automation script.
