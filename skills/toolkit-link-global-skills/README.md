# toolkit-link-global-skills

Link a project's local skills into global directories for Codex, Claude Code, and Cursor.

## What it does

- Finds local skill directories.
- Creates matching direct symlinks for each provider.
- Reports conflicts without replacing unrelated targets.

## What to expect

The skill keeps matching links unchanged. It removes only broken direct-child symlinks.

## How to use

Ask an agent to install, synchronize, repair, or clean global skill links.
