# toolkit-llm-linter

Apply selected code and writing conventions after implementation.

## What it does

- Matches the completed work to a focused rule registry.
- Asks which relevant rules to apply.
- Applies the approved rules or creates a new rule prompt.

## What to expect

The skill uses only the selected registry files. It does not apply unrelated conventions.

## How to use

Ask an agent to lint, align, clean up, polish, or apply project conventions.
