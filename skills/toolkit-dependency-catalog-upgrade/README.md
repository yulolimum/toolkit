# toolkit-dependency-catalog-upgrade

Manage shared dependency versions in pnpm or Bun monorepos.

## What it does

- Moves shared versions into a dependency catalog.
- Pins catalog versions.
- Upgrades the selected dependencies.

## What to expect

The skill checks workspace configuration and updates package references to use the catalog.

## How to use

Ask an agent to consolidate or upgrade dependency versions in a pnpm or Bun monorepo.
