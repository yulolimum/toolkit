# Flavor name

State what this flavor does to prose, and state who reads the result. Use one paragraph.

## What this flavor assumes about reading

List the conditions that support the rules below. When the rules stand on their own, remove this section.

- Write one condition on each line.

## First rule group

- Write one rule on each line. Say what to do, or say what to avoid.
- Keep each rule testable against a single sentence.
- When a rule forbids something, name the fix.

## Second rule group

- Group the rules by the decision that a writer makes, not by the part of speech.
- Use as many groups as the flavor needs.
